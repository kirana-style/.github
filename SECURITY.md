# Security policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue.

- Use GitHub's **Report a vulnerability** button on the repository's *Security* tab, or
- email **security@kirana.style**.

Include what is affected (package and version), how to reproduce it, and what an attacker could do
with it. We will acknowledge the report within five working days, keep you informed while we work
on a fix, and credit you in the advisory unless you prefer otherwise.

## Supported versions

Kirana is before 1.0. Security fixes are released for the latest minor version only.

## Scope

Everything published from this organization: the `kirana` command line, the npm packages, the
template helpers for PHP, Ruby and Elixir, and the editor extensions. Kirana's packages run no
install scripts; a published package that does is a vulnerability.
