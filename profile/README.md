<h1 align="center">Kirana</h1>

<p align="center"><b>Styling, compiled.</b></p>

Kirana is a compile-time styling system for the web. You write typed styles next to your
components; the compiler turns them into small, predictable CSS and plain class names, with no
styling runtime left in the page.

- **Every framework:** React, Next.js, Vue, Svelte, Astro, Angular, Qwik and more, and server
  templates in Laravel, Rails, Phoenix, Symfony and AdonisJS.
- **Typed:** a typo in a property or a token is a compile error, and your editor shows the CSS a
  style becomes.
- **Predictable:** later styles win, per property, the same way at build time and at runtime.

Kirana is in development and not released yet. The first release will be announced on
[kirana.style](https://kirana.style).
